# インフルエンサーDB 項目仕様（実務作業者向け）

スプレッドシートに出力される各項目が、どのデータソースに基づき、
どのような計算・判定ロジックで生成されているかをまとめる。
「この数値・コメントは何を根拠にしているか」を確認する際に参照すること。

## 用語
- **YouTube API取得値**：YouTube Data API v3から直接取得した値（加工なし、または軽微な変換のみ）。
- **ルールベース算出**：コード内の固定ロジックで機械的に算出した値。
- **Claude AI生成**：Claude（AIモデル）に動画タイトル等を渡し、自由記述・推定させた値。客観的な計算式は存在しない。
- **手動入力欄**：システムでは値を入れず、実務作業者が後から手動で記入する欄（グレー背景セル）。

## 基本情報

| 項目 | 根拠 |
|---|---|
| 活動名 | YouTube API取得値（チャンネル名） |
| チャンネルURL | YouTube API取得値（チャンネルID）から機械的に組み立てたURL |
| 年齢層 | 未実装。常に空欄（取得元データなし） |
| 拠点 | YouTube API取得値（チャンネルの`snippet.country`）。**`country`が「JP」と完全一致する場合のみ収集対象とする**（未設定チャンネルは除外）ため、本シートに載っている時点で全件「JP」になる |

## スタンス

| 項目 | 根拠 |
|---|---|
| PR案件比率 | **ルールベース算出**。直近取得動画（最大30件）のうち、タイトル＋概要欄に `#PR` `#ad` `#sponsored` `#案件` のいずれかを含む動画数 ÷ 取得動画総数。表示形式「X/30」のXがPR表記あり動画数。**検索キーワードに関連する動画だけを見ているのではなく、直近動画全体が対象**。「0/30」は直近30件にPR表記の動画が無かったことを意味する |

## オーガニック

| 項目 | 根拠 |
|---|---|
| 言及履歴 | **ルールベース算出**。直近動画タイトルのうち、検索キーワード（例:「Subnautica2」）の文字列をタイトルに含むもの一覧。PR表記の有無は判定していない（PRであっても言及があれば載る） |
| 無償取り上げ実績 | **ルールベース算出**。「言及履歴」が1件以上あれば TRUE、0件なら FALSE。**タイトルにキーワードが含まれているかどうかのみで判定**しており、実際にPR案件として依頼を受けていないかまでは確認していない（タイトル一致＝無償実績、という簡易判定） |

## 判定

| 項目 | 根拠 |
|---|---|
| 総合スコア | **Claude AI生成**。チャンネル名・登録者数・直近動画タイトル一覧のみをAIに渡し、「0.0〜10.0の総合スコア」として自由に採点させたもの。**何を合算・加重した値かという定義式はコード上に存在しない**。PR案件比率や無償取り上げ実績などシート上の他項目はスコアリングの入力に含まれていない |
| 適合度 | **Claude AI生成**。同上の情報から「検索キーワードとの適合度」を0.0〜10.0でAIに自由採点させたもの |
| オーガニック誘発可能性 | **Claude AI生成**。「高・中・低」をAIが自由判定。明確な閾値・基準はコード上にない |
| 推奨アプローチ | **Claude AI生成**。100字以内でAIが自由記述したコメント |

---

## 既知の留意点（実務上の注意）

1. **「総合スコア」「適合度」「オーガニック誘発可能性」「推奨アプローチ」は、いずれもClaude（AI）の自由推定値であり、固定の計算式・採点基準は存在しない。** 同じような動画タイトル傾向のチャンネルに似たスコアが付くことがあるが、これは厳密な根拠に基づく一致ではなくAIの推定の結果である。
2. AIへの入力情報は「チャンネル名・登録者数・直近動画タイトル一覧」のみであり、PR比率や無償取り上げ実績などシート上の他の収集データはAI判定に使われていない。
3. 「無償取り上げ実績」は、タイトルへのキーワード一致のみで判定する簡易ロジックであり、実際の契約有無・PR表記の有無までは確認していない。
4. 「拠点」はYouTubeチャンネル設定の`country`が「JP」と完全一致する場合のみ収集しているため、本シートに載っている時点で必ず「JP」表示となる（フィルタ済みのため項目として情報量は限定的）。
5. 年齢層・性別比・地域・アクティブ時間帯・投稿頻度・共演コラボ履歴・炎上履歴・所属先は、いずれも現状未実装で常に空欄。今後の拡張対象。
